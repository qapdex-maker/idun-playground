Idun — an Azure AI Foundry Agent Service for Research

Abstract. Idun is a stdlib-only client and CLI for the NatureLM-Idun-5-MoE agent hosted on Azure AI Foundry. It exposes the agent over the OpenAI responses protocol, ships a retro neon console, an MCP server, and a tenant-agnostic web playground. At Ignite we present the project end-to-end: from the Foundry agent to a Power Platform connector that lets anyone call the agent from Power Automate.

What we present

  • idun-sdk (v1.0.32) — client + CLI, 17-provider registry, retro console, MCP.
  • NatureLM-Idun-5-MoE — the Foundry agent, bound to a model-router.
  • idun-playground — live trajectory replay, no account needed.
  • Power Platform connector — independent-publisher submission (PR #4249).
