Endpoint reference

The agent is exposed via the Azure AI Foundry Agent Service OpenAI responses protocol. Try it live against the local router below.

URL

POST https://qmfi-research-project-resource.services.ai.azure.com
    /api/projects/qmfi-research-project
    /agents/NatureLM-Idun-5-MoE
    /endpoint/protocols/openai/responses?api-version=2025-05-15-preview

Request body

{
  "model": "model-router",
  "input": "Your prompt here",
  "max_output_tokens": 4096
}

warning When the agent is in the URL path, the body must set "model":"model-router". Using the agent name returns invalid_payload.
