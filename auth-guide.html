Authenticate to the endpoint

The endpoint is protected by Microsoft Entra ID. Authenticate with a bearer token — no client secret required when using a public client (device-code or managed identity).

1 · Scope and tenant

The OAuth scope must end in /.default:

https://ai.azure.com/.default

Tenant: 885f01ab-7364-4484-be0a-231d541c9e7f (QMFI-Research)

2 · Device-code flow (no Azure CLI)

On Android/Termux the Azure CLI cannot be installed. Use the bundled script (wraps azure-identity DeviceCodeCredential):

pip install -r requirements.txt
python3 scripts/device_code_login.py

The script prints a device code to ~/foundry_code.txt. Open https://login.microsoft.com/device, enter the code, sign in. The bearer token is written to ~/foundry_token.txt.

3 · Use the token

Authorization: Bearer **

The router reads the token from FOUNDRY_TOKEN, FOUNDRY_TOKEN_FILE, or ~/foundry_token.txt automatically.
